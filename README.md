# GAMES201 流体与弹簧仿真项目说明

## 项目概述
本项目包含三类物理仿真代码，均基于 Taichi 高性能并行计算框架实现，涵盖：
- `work0.py`：二维 SPH（光滑粒子流体动力学）流体仿真
- `work1.py`：一维弹簧质点链，对比显式与隐式积分方法
- `work2.py`：基于 Stable Fluids 算法的二维网格流体仿真

## 主要内容与功能

### 1. work0.py：SPH 粒子流体仿真
- 实现了标准 SPH 流体动力学，包括密度、压力、力、边界处理等。
- 支持 5000+ 粒子并行计算，展示流体流动、碰撞、反弹等物理现象。
- 可视化粒子运动轨迹，便于观察流体行为。

### 2. work1.py：弹簧质点链积分器对比
- 构建一维弹簧链，端点固定，中间质点受重力和弹簧力作用。
- 显式欧拉与隐式欧拉积分器并行演示，直观对比稳定性和数值误差。
- 牛顿迭代法近似隐式积分，展示刚性系统的高效解法。
- GUI 同时绘制两种积分结果，红色为显式，蓝色为隐式。

### 3. work2.py：Stable Fluids 网格流体仿真
- 采用 Jos Stam 1999 Stable Fluids 算法，支持大规模二维网格流体模拟。
- 包含半拉格朗日平流、扩散、压力投影、边界处理等核心步骤。
- 支持鼠标交互注入流体，实时可视化流体密度场。
- 可调节初始流体量和交互注入强度，画面丰富。

## 性能与并行优势
- 所有核心计算均用 Taichi kernel 并行实现，充分利用 CPU/GPU 多核能力。
- SPH 粒子仿真可轻松扩展至数万粒子，性能远超纯 Python 实现。
- 网格流体仿真支持高分辨率（如 400x400 及以上），实时交互不卡顿。
- 隐式积分器和压力投影均用矩阵运算/迭代法，数值稳定性高。

## 运行方式：
1. python版本为3.6，使用conda环境：`conda create -n taichi python=3.6`
2. conda环境激活：`conda activate taichi`
3. 安装依赖：`pip install taichi numpy`
4. 运行任意脚本：`python work0.py`、`python work1.py`、`python work2.py`
